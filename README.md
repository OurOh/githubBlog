# githubBlog  
**GitHub 블로그 만들기 연습 프로젝트**  

---

## 📋 프로젝트 개요  
**GitHub 블로그**를 만들어보는 연습을 위해 진행되었습니다.  
HTML, CSS, JavaScript를 활용해 블로그 페이지를 구성하고 다양한 주제의 콘텐츠를 작성해보고자 했습니다.

---

## 🚀 주요 기능  
- **블로그 메인 페이지**: 다양한 게시글을 나열하는 메인 화면  
- **게시글 페이지**: 개별 게시글을 HTML로 작성하고 링크 연결  
- **카테고리별 페이지**: 스포츠, 음식, 웹 개발 등 주제별 콘텐츠 페이지 생성  
- **연락처 페이지**: 블로그 방문자와 소통할 수 있는 페이지 구현  

---

## 🛠️ 기술 스택  
- **Frontend**: HTML, CSS, JavaScript  
- **Version Control**: Git & GitHub
